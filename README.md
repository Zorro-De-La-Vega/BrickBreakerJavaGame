# 🎮 Brick Breaker - Levels Edition

A classic arcade-style brick breaker game built with Java Swing, featuring progressive levels, power-ups, and dynamic difficulty.

## 🕹️ How to Play

- **Arrow Keys** - Move paddle left/right
- **P** - Pause/Resume game
- **Enter** - Start next level or restart after game over

## ✨ Features

- **Progressive Levels** - Increasing difficulty with more bricks and faster ball speed
- **Dynamic Patterns** - Three unique brick layouts (solid, checkerboard, stripes)
- **Power-Ups** - Collect cyan squares to expand your paddle
- **Sound Effects** - Audio feedback for collisions and events
- **Score Tracking** - Earn points for each brick destroyed

## 🚀 How to Run

1. Clone the repository
2. Open `BrickBreakerGame.java` in your Java IDE
3. Run the main method
4. Enjoy!

**Requirements:** JDK 8 or higher

## 📝 Game Rules

- Break all bricks to complete each level
- Don't let the ball fall below the paddle
- Catch power-ups to increase paddle size
- Ball speed increases as you break more bricks
